# Acting on a request that does not say which item

1. Look before you act: list the items and find every one the request could mean.
2. If more than one qualifies and the request does not single one out, do not guess and do not
   change anything — ask the user which one they mean, naming the candidates.
3. When the user names the item, restock that one only: one update to its target, keep the ticket.
4. Never confirm the restock: the other low items are still waiting on the supplier, and the
   server refuses a confirm while anything is low.
5. Report exactly what you changed and the total the server's summary gives.
